03. API

One request, clean JSON.

Query by country, region and date range. No key, no sign-up. Every holiday comes with its local name, translations, category and source.

  • Region or nation, never both. A region returns its complete set, nationwide days included.
  • is_observed marks a shifted date that is still a day off.
  • is_estimated marks dates that depend on moon sighting and can still move.
  • Every row knows its source and licence.
